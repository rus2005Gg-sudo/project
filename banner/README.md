# Практическая работа 2 — рекламный баннер VaiaVPN

Готовый баннер 800×400: `vaiavpn_banner.png`, `vaiavpn_banner.jpg`,
файл со слоями — `vaiavpn_banner.xcf` (открывается в GIMP 2.6 и новее).

## Как сделать вручную в GIMP 2.6.11

1. **Новый проект.** Файл → Создать → 800×400.
2. **Фон.** Цвет переднего плана `#000908`, фона `#0E4614`. Инструмент
   «Градиент», протянуть сверху вниз.
3. **Рамка.** Слой → Создать слой (прозрачный). Выделение прямоугольником
   с отступом 12 px от краёв, Правка → Обвести выделение, 5 px,
   цвет `#A6DE1E`. Выделение → Снять.
4. **Импорт изображения.** Файл → Открыть как слои → `src/lock.png`,
   передвинуть вправо. Цвет → Яркость-Контраст (яркость +20, «осветлить»),
   Фильтры → Свет и тень → Отбрасываемая тень (6, 6, размытие 10).
5. **Текст** (инструмент «Текст», шрифт Sans Bold):
   - «VaiaVPN» — 80 px, `#A6DE1E` + отбрасываемая тень;
   - «Бесплатно для всех» — 36 px, белый;
   - «до 1 ноября!» — 36 px, `#C8F03A`;
   - «Наш бот в Telegram:» — 24 px, белый;
   - «@VAIAVPN_bot» — 38 px, `#A6DE1E`;
   - «Ссылка на бонус — в закрепе нашего ТГ-канала» — 20 px, белый.
6. **Экспорт.** Файл → Сохранить как… → `.png` или `.jpg`.

## Сборка автоматически

`src/vaiavpn-banner.scm` (Script-Fu) повторяет те же шаги:

```sh
python3 src/make_lock.py src/lock.png
gimp -i -b '(begin (load "src/vaiavpn-banner.scm") (vv-build "src/lock.png" "./" FALSE))' \
        -b '(gimp-quit 0)'
```

Если положить скрипт в папку `scripts` профиля GIMP, он появится в меню
Файл → Создать → «VaiaVPN баннер...».
