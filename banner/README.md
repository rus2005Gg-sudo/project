# Практическая работа 2 — рекламный баннер VaiaVPN

Готовый баннер 800×400: `vaiavpn_banner.png`, `vaiavpn_banner.jpg`,
файл со слоями — `vaiavpn_banner.xcf` (открывается в GIMP 2.6 и новее).

## Как сделать вручную в GIMP 2.6.11

1. **Новый проект.** Файл → Создать → 800×400.
2. **Импорт изображений.**
   - Файл → Открыть как слои → `src/earth_night.jpg`.
     Слой → Масштабировать слой → 800×400.
   - Цвет → Тонирование (тон 85, насыщенность 70) — карта становится зелёной.
   - Цвет → Яркость-Контраст (яркость +20, контраст +40) — осветлить огни городов.
   - Новый прозрачный слой «Затемнение», инструмент «Градиент»
     «Основной в прозрачный», чёрный, протянуть слева направо — чтобы читался текст.
   - Файл → Открыть как слои → `src/phone.jpg`. Обрезать по руке с телефоном,
     уменьшить до 240×278, поставить справа.
   - Под фото новый слой чуть больше фото, залить `#A6DE1E` — рамка.
     Слой → Объединить с предыдущим.
   - Инструмент «Вращение» — повернуть фото на 4°.
   - Фильтры → Свет и тень → Отбрасываемая тень (8, 8, размытие 12).
3. **Работа с текстом** (инструмент «Текст», шрифт Arial Bold):
   - «VaiaVPN» — 64 px, `#A6DE1E` + отбрасываемая тень;
   - «Защита. Свобода. Без границ.» — 20 px, белый;
   - «VPN бесплатно для всех» — 32 px, белый;
   - «до 1 ноября!» — 46 px, `#C8F03A` + отбрасываемая тень;
   - «Подключайся через бота в Telegram:» — 20 px, белый;
   - «@VAIAVPN_bot» — 38 px, `#A6DE1E`.
4. **Полоса снизу.** Новый слой, прямоугольное выделение по нижним 50 px,
   залить чёрным, непрозрачность слоя 65%. Сверху текст «Ссылка на бонус —
   в закрепе нашего ТГ-канала!», 20 px, белый.
5. **Экспорт.** Файл → Сохранить как… → `.png` или `.jpg`.

## Сборка автоматически

`src/vaiavpn-banner.scm` (Script-Fu) повторяет те же шаги:

```sh
gimp -i -b '(begin (load "src/vaiavpn-banner.scm")
                   (vv-build "src/earth_night.jpg" "src/phone.jpg" "./" FALSE))' \
        -b '(gimp-quit 0)'
```

Если положить скрипт в папку `scripts` профиля GIMP, он появится в меню
Файл → Создать → «VaiaVPN баннер...».
