# Практическая работа 2 — рекламный баннер «Уроки шахмат»

Готовый баннер 800×400: `chess_banner.png`, `chess_banner.jpg`,
файл со слоями — `chess_banner.xcf` (открывается в GIMP 2.6 без ошибок,
текст остаётся редактируемым).

## Как сделать вручную в GIMP 2.6.11

1. **Новый проект.** Файл → Создать → 800×400.
2. **Фон.** Заливка узором «Wood #1» (Правка → Залить текстурой).
   Цвет → Яркость-Контраст (яркость −40) — затемнить. Новый прозрачный слой,
   «Градиент» «Основной в прозрачный», чёрный, слева направо.
3. **Доска.** Новый слой 320×320, Фильтры → Визуализация → Узор → Шахматная
   доска, размер клетки 40, цвета `#F0D9B5` и `#B58863`. Под ним слой 336×336
   цвета `#462814` — окантовка, объединить. Инструмент «Перспектива» — положить
   доску «на стол». Фильтры → Свет и тень → Отбрасываемая тень.
4. **Импорт изображений.** Файл → Открыть как слои → `src/bk.svg` (король,
   150 px) и `src/wn.svg` (конь, 170 px), поставить на доску, каждой фигуре
   отбрасываемую тень.
5. **Текст** (Arial Bold / Arial):
   - «Уроки шахмат» — 62 px, `#F5E6C8` + тень;
   - «Тренер по шахматам — для детей и взрослых» — 20 px, `#E8BA46`;
   - три пункта «• Обучение с нуля до разряда», «• Занятия онлайн и очно»,
     «• Первое занятие — бесплатно!» — 22 px, белый;
   - «Запишись на пробное занятие:» — 20 px, `#F5E6C8`;
   - «8 (900) 000-00-00» — 40 px, `#E8BA46` + тень (номер-заглушка, замените).
6. **Рамка.** Выделение с отступом 10 px, Правка → Обвести выделение, 3 px, `#E8BA46`.
7. **Экспорт.** Файл → Сохранить как… → `.png` или `.jpg`.

## Сборка автоматически

```sh
gimp -i -b '(begin (load "src/chess-banner.scm") (ch-build "src/wn.svg" "src/bk.svg" "./" FALSE))' \
        -b '(gimp-quit 0)'
```

## Источники изображений

- `src/wn.svg`, `src/bk.svg` — шахматные фигуры Cburnett (Colin M. L. Burnett),
  из пакета Ubuntu `pychess`, GPL-3+.
- Узор «Wood #1» входит в стандартный набор GIMP.
